A RENDERER. NOT A SCREENSHOT.

Geometry in.
Pixels out.

The native WebGPU renderer uses instanced draw calls, GGX/Schlick material shading, directional shadow maps and multisample antialiasing. The graph cooks off the UI thread in a Web Worker.

Without a usable GPU, the workspace falls back to WebGL2 or a labeled CPU depth-buffered preview. Fallbacks deliberately expose their reduced rendering capabilities.

SHARED WORK, EXPLICIT PERMISSIONS

Build together.
Keep the history.

The included Node server provides accounts, team projects, invitations, live presence and operation streaming. SQLite stores committed edits and checkpoints.

Independent field changes merge. Same-field changes follow server arrival order. Rejected edits are surfaced rather than silently discarded. This is not a CRDT or an enterprise identity system.
